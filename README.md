# Abo Zahra Pro — نسخة أندرويد أولية

هذه ملفات مشروع Android Studio مبدئية لتطبيق مدير تحميلات بلا إعلانات أو SDK إعلاني.

## الموجود في النسخة الأولية
- إدخال رابط مباشر ولصقه من الحافظة بزر واضح.
- إرسال روابط متعددة واحدًا بعد الآخر إلى Android DownloadManager.
- إشعارات التنزيلات والتشغيل في الخلفية عبر مدير التنزيلات في أندرويد.
- حفظ الملفات في مجلد Downloads.
- واجهة عربية بسيطة.

## حدود النسخة الأولية
- هذا ZIP يحتوي على **مصدر المشروع وليس ملف APK جاهزًا**.
- التحميل يدعم الروابط المباشرة التي تسمح بها المواقع؛ روابط صفحات الفيديو أو المواقع التي تتطلب جلسة دخول قد لا تعمل.
- استكمال التحميل يعتمد على دعم الخادم ومدير التنزيلات.
- لا توجد مراقبة خفية للحافظة؛ المستخدم يضغط زر «لصق الرابط» احترامًا لخصوصيته.
- لا توجد حاليًا واجهة متقدمة لإيقاف كل مهمة/استئنافها أو مدير مهام داخلي؛ هذه خطوات لاحقة.
- يحتاج البناء إلى Android Studio وJDK متوافقين واتصال لتنزيل أدوات Gradle.

## طريقة بناء APK
1. فك ضغط الملف.
2. افتح مجلد `HammelPlusAndroid` في Android Studio.
3. اسمح بمزامنة Gradle وتنزيل الأدوات المطلوبة.
4. من القائمة: Build > Build Bundle(s) / APK(s) > Build APK(s).
5. عند نجاح البناء سيظهر رابط/مسار APK داخل Android Studio، غالبًا في `app/build/outputs/apk/debug/app-debug.apk`.

لا توزّع نسخة الاختبار على أجهزة أخرى قبل اختبار الروابط والتنزيلات على جهازك.
